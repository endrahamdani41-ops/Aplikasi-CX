KELAS 8 • ALGORITMA & STRUKTUR DATA

Ubah Infix menjadi Postfix 🚀

Pelajari bagaimana komputer mengatur urutan operasi menggunakan Stack. Ikuti materi, lihat simulasi, lalu uji kemampuanmu.

+
*
( )

🎯 Tujuan

Memahami infix, postfix, prioritas operator, dan peran stack.

🧠 Fokus

Amati aturan, lakukan langkah demi langkah, kemudian cek hasil.

🏆 Tantangan

15 soal + simulasi + drag & drop + tantangan bonus.

MATERI 1

Kenali Infix & Postfix

📌 Infix

Operator berada di antara operand.

A + B

Contoh sehari-hari: 5 + 3.

📌 Postfix

Operator ditulis setelah operand.

AB+

Postfix membantu komputer memproses urutan operasi dengan lebih sederhana.

📚 Stack

Stack memakai prinsip LIFO (Last In, First Out).

TOP → [ * ] [ + ]

Dalam konversi, operator disimpan sementara di stack.

Prioritas Operator

PrioritasOperatorKeterangan
1( )Tanda kurung
2^Pangkat
3* /Perkalian / Pembagian
4+ -Penjumlahan / Pengurangan

1️⃣ Operand

Langsung masukkan ke output.

2️⃣ Operator

Periksa prioritas dengan operator di stack.

3️⃣ Kurung

Jika selesai membaca, keluarkan isi stack sesuai aturan.

MATERI 2

Contoh Langkah demi Langkah

Contoh: A + B * C

Karena * memiliki prioritas lebih tinggi daripada +, operator * akan diproses lebih dahulu.

SimbolOutputStackAlasan

+A+Operator → stack
