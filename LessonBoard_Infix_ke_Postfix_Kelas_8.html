Materi, contoh, simulasi, kuis 15 soal, drag & drop, dan tantangan bonus.

Kebalikannya: membaca postfix menjadi infix, lengkap dengan kuis 15 soal & tantangan.

INFIX → POSTFIX • MATERI 1

Kenali Infix & Postfix

📌 Infix

Operator berada di antara operand.

A + B

Contoh sehari-hari: 5 + 3.

📌 Postfix

Operator ditulis setelah operand.

AB+

Postfix membantu komputer memproses urutan operasi dengan lebih sederhana.

📚 Stack

Stack memakai prinsip LIFO (Last In, First Out).

TOP → [ * ] [ + ]

Dalam konversi, operator disimpan sementara di stack.

Prioritas Operator

PrioritasOperatorKeterangan
1( )Tanda kurung
2^Pangkat
3* /Perkalian / Pembagian
4+ -Penjumlahan / Pengurangan

1️⃣ Operand

Langsung masukkan ke output.

2️⃣ Operator

Periksa prioritas dengan operator di stack.

3️⃣ Kurung

Jika selesai membaca, keluarkan isi stack sesuai aturan.

POSTFIX → INFIX • MATERI

Kebalikan: Postfix → Infix

🔁 Mengapa Perlu Kebalikannya?

Jika Infix → Postfix digunakan untuk mengubah notasi agar mudah diproses komputer, maka Postfix → Infix digunakan untuk membaca kembali hasil postfix agar mudah dipahami manusia.

AB+C* → ( ( A + B ) * C )

📜 Algoritma Postfix → Infix

Gunakan stack untuk menyimpan string (bukan hanya simbol).

1️⃣ Baca dari Kiri

Scan postfix satu per satu dari kiri ke kanan.

2️⃣ Jika Operand

Push operand ke stack sebagai string.

3️⃣ Jika Operator

Pop 2 operand teratas → gabungkan jadi (op1 operator op2) → push kembali.

📝 Contoh: AB+C*

TokenAksiStack (atas → bawah)
APush operand[ A ]
BPush operand[ B , A ]
+Pop B, A → buat (A+B) → push[ (A+B) ]
CPush operand[ C , (A+B) ]
*Pop C, (A+B) → buat ((A+B)*C)[ ((A+B)*C) ]
SelesaiHasil: ((A+B)*C)
